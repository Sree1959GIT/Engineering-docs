═══════════════════════════════════════════════════════════════════════════════
STEP 4: CREATE .env FILE WITH YOUR API KEY
═══════════════════════════════════════════════════════════════════════════════

First, get your API key from: https://console.anthropic.com/api-keys

Then, copy and paste:

────────────────────────────────────────────────────────────────────────────────
cd ~/engineering-docs
cp .env.example .env
────────────────────────────────────────────────────────────────────────────────

Now EDIT the .env file:

────────────────────────────────────────────────────────────────────────────────
nano .env
────────────────────────────────────────────────────────────────────────────────

You'll see:
  ANTHROPIC_API_KEY=sk-ant-...

Replace "sk-ant-..." with your ACTUAL API key (copy from https://console.anthropic.com/api-keys)

To save in nano:
  1. Press Ctrl+O
  2. Press Enter
  3. Press Ctrl+X

Done! ✓

═══════════════════════════════════════════════════════════════════════════════
STEP 8: ENABLE GOOGLE DRIVE MCP IN CLAUDE CODE
═══════════════════════════════════════════════════════════════════════════════

In Claude Code (not terminal):

1. Click "Customize" (left sidebar or account menu)
2. Click "Connectors"
3. Find "Google Drive"
4. Click "Connect"
5. A browser window opens → Sign in with your Google account
6. Click "Allow" to give Claude Code permission
7. Back in Claude Code → You should see "Connected" next to Google Drive

✓ Google Drive MCP is now active!

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "Command not found: claude code"
Solution: Install Claude Code first
  → See: https://docs.claude.com/en/docs/claude-code/overview

Problem: "ModuleNotFoundError: No module named 'anthropic'"
Solution: Install dependencies again
  $ cd ~/engineering-docs && pip install anthropic python-dotenv

Problem: "ANTHROPIC_API_KEY not found"
Solution: Check your .env file
  $ cd ~/engineering-docs && cat .env | grep ANTHROPIC_API_KEY
  Should show: ANTHROPIC_API_KEY=sk-ant-...
  If blank, edit: nano .env

Problem: "Google Drive MCP not connected"
Solution: In Claude Code, go to Customize → Connectors
  Is Google Drive showing "Connected"? If not, click "Connect" and re-authorize.
