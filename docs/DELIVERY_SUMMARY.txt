================================================================================
MCP CONNECTORS NEEDED
================================================================================

REQUIRED: Google Drive MCP
  URL: https://drivemcp.googleapis.com/mcp/v1
  Setup: 2 minutes (see MCP_QUICK_REFERENCE.md or MCP-SETUP.md)
  What it does: Creates folders in Google Drive, uploads PDFs/CSVs
  Cost: Free (uses your existing Google Drive)

OPTIONAL: Gmail MCP
  URL: https://gmailmcp.googleapis.com/mcp/v1
  Setup: 2 minutes (same as Google Drive)
  What it does: Sends completion notification emails
  Cost: Free

OPTIONAL: Google Calendar MCP
  URL: https://calendarmcp.googleapis.com/mcp/v1
  Setup: 2 minutes
  What it does: Creates calendar events for documentation reviews
  Cost: Free

OPTIONAL: Airtable MCP
  URL: https://mcp.airtable.com/mcp
  Setup: 5 minutes (need Airtable account first)
  What it does: Persists connection tables in Airtable database
  Cost: Free (Airtable account needed)

HOW TO CONNECT MCPs IN CLAUDE CODE:
  1. Open Claude Code
  2. Click "Customize" (sidebar)
  3. Click "Connectors"
  4. Find the MCP → Click "Connect"
  5. Authorize with browser
  6. You should see "Connected" status

COST & PERFORMANCE
================================================================================

Per-Task Execution
  Time:  3–4 minutes (mostly Opus work)
  Cost:  ~$0.15 per diagram
  Savings: ~70% vs. Opus-only approach

Cost Breakdown (Example Task: 3-phase Motor Control)
  Haiku triage:     1,200 input + 350 output tokens  = $0.001
  Opus work:        4,500 input + 2,800 output tokens = $0.150
  Google Drive:     (no token cost)                  = $0.000
                                                     --------
  TOTAL:                                              ~$0.151

Compare:
  Using Opus for triage + work: ~$0.50 per diagram
  Using Haiku + Opus: ~$0.15 per diagram
  Savings: 70% (or $0.35 per diagram)

Models Used
  Haiku 4.5-20251001 (triage): $1/$5 per million tokens
  Opus 4.8 (work):            $5/$25 per million tokens

Output Formats
  - PDF (professional schematic with title block, IEC 60617 symbols)
  - SVG (editable vector graphic)
  - CSV (connection table: From → Via → To → Notes)
  - Text (block descriptions, [VERIFY] items list)

================================================================================
SECURITY & BEST PRACTICES
================================================================================

API Key Security
  - Store ANTHROPIC_API_KEY in .env, never in code
  - DO NOT commit .env to version control
  - Add .env to .gitignore: echo ".env" >> .gitignore
  - Rotate keys periodically if managing multiple users

Google Drive Sharing
  - Default: "Anyone with link can view"
  - Modify in orchestrator.py if you want stricter permissions
  - All outputs are automatically saved to Drive with timestamps

Data Privacy
  - Your task descriptions are sent to Anthropic's API (Haiku & Opus models)
  - All outputs are saved to your Google Drive (not shared elsewhere)
  - See Anthropic's privacy policy: https://www.anthropic.com/privacy

TROUBLESHOOTING QUICK START

Solution: In Claude Code, Customize → Connectors → Google Drive → Connect

Problem: "python orchestrator.py: command not found"
Solution: cd ~/engineering-docs && python orchestrator.py

Problem: "Module 'anthropic' not found"
Solution: pip install anthropic python-dotenv

Problem: "Opus timeout"
Solution: Task is large; increase timeout in orchestrator.py (see comments)
