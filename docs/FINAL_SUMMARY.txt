🚀 QUICK START (5 MINUTES)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Download all 11 files from /mnt/user-data/outputs/ to your computer

2. Create project folder:
   mkdir -p ~/engineering-docs
   cd ~/engineering-docs

3. Copy files there (or move them)

4. Also copy wiring-block-diagrams.skill from outputs

5. Edit .env:
   cp .env.example .env
   nano .env
   # Paste: ANTHROPIC_API_KEY=sk-ant-...
   # Save: Ctrl+O, Enter, Ctrl+X

6. Install Python packages:
   pip install anthropic python-dotenv

7. Enable Google Drive MCP:
   - Open Claude Code
   - Click Customize → Connectors
   - Find Google Drive → Click Connect
   - Authorize your Google account

8. Test:
   python orchestrator.py

That's it! You're ready to run.
