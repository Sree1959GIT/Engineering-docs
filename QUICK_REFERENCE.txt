⚠️ TROUBLESHOOTING

   Problem: "(venv) not showing"
   Fix: Run: venv\Scripts\activate

   Problem: "No module named 'anthropic'"
   Fix: pip install -r requirements.txt

   Problem: "No API key found"
   Fix: python auth.py --setup
        OR: paste key when prompted on first run

   Problem: "Invalid API key format"
   Fix: Key must start with "sk-ant-"
        Get real key: console.anthropic.com/api-keys

   Problem: "scripts folder not found"
   Fix: Verify files in: scripts/
        Run: dir scripts\
