❓ COMMON QUESTIONS
═══════════════════════════════════════════════════════════════════════════════

Q: Is Python installed on my Windows?
A: Open Command Prompt and run: python --version
   If it shows a version, Python is installed ✓
   If not, download from: https://www.python.org/downloads/

Q: Where do I get my API key?
A: Go to: https://console.anthropic.com/api-keys
   Click "Create Key"
   Copy it to your .env file

Q: How do I know if Google Drive MCP is working?
A: In Claude Code, go to Customize → Connectors
   If you see "Connected" next to Google Drive, it's working ✓

Q: Can I run this on Mac/Linux?
A: Yes! Use the same files. Instead of:
     cd C:\Fixtures\engineering-docs
   Use:
     cd ~/engineering-docs
   Everything else is the same.

Q: How do I troubleshoot issues?
A: Check WINDOWS_SETUP_GUIDE.md → Troubleshooting section
